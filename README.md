# fennel-ls-bin

A bunch of scripts that builds [fennel-ls](https://git.sr.ht/~xerool/fennel-ls) and publishes a release.

| Mode         | Upstream      | Tag              |
| ------------ | ------------- | ---------------- |
| `prerelease` | latest commit | `pre-<sha12>`    |
| `release`    | latest tag    | same as upstream |
